Project: Endless Runner

An endless running game where obstacles, collectibles, and platforms are randomly spawned at increasing rate
Programmed with Java and implemented with Java Swing
Features Geometry Dash components

Technical Information:
Language: Java
Graphics/UI: Java Swing (Rendering & Event Loop)
Architecture: Object-Oriented design patterns implementing real-time collision detection and state management.

Key Features:
Core Systems: Developed robust collision detection and physics engines to handle high-velocity object interactions.
Architectural Design: Implemented object oriented programming concepts including inheritance and encapsulation to create a modular codebase, ensuring that game entities (obstacles vs. collectibles) could be easily extended and maintained.
Application Logic: Designed a state management system to handle transitions between active gameplay, score tracking, and difficulty scaling.
Event Handling: Utilized Java Swing for real-time rendering and input processing, focusing on responsive system feedback.
